# Put this on Deep's GitHub profile

1. Sign in to the **Deep1454** GitHub account.
2. Create a **public** repository named exactly **Deep1454**. This special repository displays its root README on the profile.
3. Open the repository and choose **Add file → Upload files**.
4. Upload **README.md** and the entire **assets** folder from this package. Keep the assets folder name and structure intact. If GitHub cannot upload a folder from the browser, create it with Git locally or upload the files inside an assets directory through the web editor.
5. Commit the files to the repository's default branch. Open https://github.com/Deep1454 to see the profile.

The repository should contain:

- README.md
- assets/hero.svg
- assets/eventbooking.svg
- assets/flashify.svg
- assets/typerush.svg
- assets/employees.svg

Do not upload the enclosing deep1454-profile folder itself. README.md belongs at the repository root. SETUP.md and the preview folder are for your reference and do not need to be uploaded.

## What is included

- An original dark header with lavender and mint accents, a pulsing status light, blinking cursor and moving accent line.
- Four original project cards that link to Deep's existing repositories.
- An introduction and technology matrix grounded in his public project READMEs, manifests and code structure.
- A collapsible section connecting technologies to the projects where they appear.
- Accessible image descriptions and responsive SVG artwork.

The artwork is included locally and has no image-hosting dependency. The skill icons and two badges use skillicons.dev and shields.io; their descriptive alt text remains if those external services are temporarily unavailable. SVG animation support depends on the viewer; the header remains readable as a still image.

The file preview/artwork-preview.png shows the included artwork. Open preview/profile-preview.html in a browser for a local approximation of GitHub's dark Markdown layout. GitHub controls its table borders, margins and mobile rendering. The project descriptions do not claim production deployment, employment, performance results or sole authorship.
